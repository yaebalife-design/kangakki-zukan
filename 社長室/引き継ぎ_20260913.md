### 作ったもの：`ツール/publish.py`
ドメイン取得後、**1コマンドで「URL差し替え→全1,482ページ再生成→秘密情報検査→git→push→デプロイ」**まで通る。

```
python ツール/publish.py --domain kangakki-zukan.com            # 差し替え・再生成・検査まで（安全。pushしない）
python ツール/publish.py --domain kangakki-zukan.com --push     # ＋GitHubへ（社長承認後）
python ツール/publish.py --domain kangakki-zukan.com --deploy   # ＋Cloudflare Pagesへ（社長承認後）
python ツール/publish.py --check-only                           # 秘密情報の検査だけ
```

**安全装置**：品質検査がエラー0でなければ止まる／秘密情報が1件でも見つかれば push しない（GA4・UA・AdSense・Amazonタグ・もしもa_id・A8・AWSキー・GitHubトークン・秘密鍵・メールアドレス・.env/.pem の混入を検査）。
